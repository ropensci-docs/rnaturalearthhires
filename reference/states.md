# state (admin level 1) polygons from Natural Earth

For all world countries at scale 1:10m (high).

## Usage

``` r
states10
```

## Format

A `sf` `data.frame`

An object of class `sf` (inherits from `data.frame`) with 4596 rows and
122 columns.

## Source

[http//www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_1_states.zip](https://docs.ropensci.org/rnaturalearthhires/reference/http/www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_1_states.zip)

## Slots

- `data`:

  A data frame with attributes
