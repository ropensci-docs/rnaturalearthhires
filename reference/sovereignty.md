# world sovereignty polygons from Natural Earth

sovereignty polygons at scale 1:10m (large). There are fewer sovereign
states than countries e.g. the Falkland Islands are included with the
United Kingdom.

## Usage

``` r
sovereignty10
```

## Format

A `sf` `data.frame`

An object of class `sf` (inherits from `data.frame`) with 209 rows and
169 columns.

## Source

[http//www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_0_sovereignty.zip](https://docs.ropensci.org/rnaturalearthhires/reference/http/www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_0_sovereignty.zip)
