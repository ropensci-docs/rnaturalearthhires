# world country polygons from Natural Earth

at scale 1:10m (large)

## Usage

``` r
countries10
```

## Format

A `sf` `data.frame`

An object of class `sf` (inherits from `data.frame`) with 258 rows and
169 columns.

## Source

[http//www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_0_countries.zip](https://docs.ropensci.org/rnaturalearthhires/reference/http/www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_0_countries.zip)

## Slots

- `data`:

  A data frame with country attributes
