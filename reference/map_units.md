# world map_unit polygons from Natural Earth

map_unit polygons at scale 1:10m (large). There are more map_units than
countries e.g. United Kingdom is split into England, Scotland, Wales and
Northern Ireland.

## Usage

``` r
map_units10
```

## Format

A `sf` `data.frame`

An object of class `sf` (inherits from `data.frame`) with 298 rows and
169 columns.

## Source

[http//www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_0_map_units.zip](https://docs.ropensci.org/rnaturalearthhires/reference/http/www.naturalearthdata.com/download/10m/cultural/ne_10m_admin_0_map_units.zip)
